# 个贷违约数据清洗与特征工程

## 项目目标

为个人贷款违约预测准备可建模数据，并将每一步处理变成可复核的过程记录。

## 数据规模

- 原始数据：10,000 行 × 29 列
- 原始违约率：16.83%
- 固定随机种子抽取 80%：8,000 条开发样本
- 最终处理后：51 列、8,000 行

原始数据不包含在仓库中；如需运行，请将数据路径通过命令行传入，并遵守数据许可。

## 处理步骤

1. 删除标识、日期和题目说明要求剔除的字段。
2. 先固定 80% 抽样，形成 `data0`。
3. 定性变量用众数填补，定量变量用中位数填补，并保留填补日志。
4. 按业务语义合并低频类别；有序变量按业务等级编码，名义变量按频数降序编码。
5. 对强偏态定量变量比较原值、平方根、`ln(1+x)`、1%/99% 截尾等候选方案，按偏度绝对值选择。
6. 对 `|r| >= 0.85` 的近似冗余变量，优先保留与目标变量相关性更强者。

## 关键结果

| 检查项 | 结果 |
| --- | --- |
| 高共线变量对 | `total_loan` / `monthly_payment`，r = 0.925 |
| 高共线变量对 | `scoring_low` / `scoring_high`，r = 0.889 |
| 剔除变量 | `monthly_payment`、`scoring_high` |
| 输出规模 | 8,000 × 51 |

## 运行

```bash
python -m pip install -r requirements.txt
python preprocess_analysis.py --xls data/raw.xls --out results
```

## 我的复盘

- 先抽样再计算统计量，可以保证后续 `data0` 到 `data3` 的处理口径一致。
- 类别合并不是机械操作，需要结合变量业务含义与等级顺序。
- 对冗余变量不能只看相关系数，还应结合目标变量相关性解释取舍理由。
